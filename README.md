# Gujarat ITI Distance Finder
1. Extract the outer download once. Keep address_images.zip zipped.
2. Upload all seven files together to the root of your GitHub repository on main. Commit and replace older files of the same names.
3. In Streamlit Community Cloud use the same repository, branch main, main file app.py. For a new deployment choose Python 3.12.
4. Locally, install with python -m pip install -r requirements.txt and run python -m streamlit run app.py.

Pick one or two origins by searching, clicking the map or entering coordinates. All 289 ITIs remain listed. 274 have approximate locality pins, so the km values measure straight-line distances to localities. The remaining 15 have no distance. Online geocoding and street tiles need internet. Each address image opens directly from address_images.zip.
